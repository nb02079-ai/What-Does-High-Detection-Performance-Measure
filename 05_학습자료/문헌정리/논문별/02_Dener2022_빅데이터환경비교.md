# Dener et al. (2022) — 빅데이터 환경에서 9개 모델 비교

> **서지**: Dener, M., Ok, G., & Orman, A. (2022). Malware detection using memory analysis data in big data environment. *Applied Sciences*, 12(17), 8604. doi:10.3390/app12178604
> **소속**: 가지대, 앙카라 이을드름 베야즛대 (튀르키예)
> **확인 수준**: ✅ 본문 전체 (출판사 원문, 2026-09-30) — 이 문서는 그때 기록한 내용만 쓴다. 학습 문서를 쓰는 시점(2026-10-01)에는 원문 재열람이 접근 제한으로 실패해, **기록에 없는 세부(9개 모델의 전체 목록 등)는 넣지 않았다**

---

## 1. 한 줄 요약

PySpark 기반의 빅데이터 환경에서 머신러닝·딥러닝 모델 9종을 CIC-MalMem-2022 이진 분류에 적용해, **로지스틱 회귀가 99.97%**로 가장 높았다고 보고한 비교 연구다.

## 2. 왜 이 논문을 읽나

- 본 연구 서론과 2.2.3에서 "후속 연구들이 99.9~99.99%를 보고했다"의 근거 중 하나다
- **선형 모델인 로지스틱 회귀가 거의 완벽한 정확도**를 냈다는 점이 중요하다. 복잡한 모델이 필요 없다는 것은, 과제 자체가 쉽다는 신호일 수 있다
- 본 연구가 **2차 인용의 수치를 그대로 옮기다 틀린** 실제 사례이기도 하다

---

## 3. 미리 알아둘 개념

| 개념 | 쉬운 설명 |
|---|---|
| **PySpark** | 대용량 데이터를 여러 컴퓨터에 나눠 처리하는 Apache Spark를 파이썬으로 쓰는 도구 |
| **로지스틱 회귀** | 특징들의 가중합을 확률로 바꿔 두 클래스를 가르는 **선형** 모델. 결정 경계가 직선(고차원에선 평면)이다 |
| **AUC** | 모든 임계값에서의 판별 능력을 하나로 요약한 값. 1이면 악성과 정상의 점수가 전혀 겹치지 않는다 |
| **무작위 분할 반복** | 데이터를 무작위로 나눠 학습·시험하는 것을 여러 번 반복하고 평균을 내는 방식 |
| **균형 데이터셋** | 클래스별 샘플 수가 같은 데이터셋. CIC-MalMem-2022는 정상·악성 각 29,298건 |

---

## 4. 논문이 풀려는 문제

제목 그대로, **빅데이터 처리 환경(PySpark)에서** 여러 모델이 메모리 기반 악성코드 탐지를 얼마나 잘하는지 비교했다. *(빅데이터 환경을 택한 동기의 세부는 기록하지 않았으므로 여기서는 쓰지 않는다)*

## 5. 방법

| 항목 | 내용 |
|---|---|
| 데이터 | CIC-MalMem-2022 균형판 58,596건 (정상·악성 각 29,298) |
| 과제 | 이진 분류 (정상/악성) |
| 전처리 | 모든 덤프에서 값이 0인 특징 3개 제거 — `pslist.nprocs64bit`, `handles.nport`, `svcscan.interactive_process_services` |
| 분할 | 덤프 단위 **70/30 무작위 분할을 10회 반복**해 평균 |
| 모델 | 머신러닝·딥러닝 9종 (PySpark 환경) |

**데이터셋에 대한 서술**: 악성 덤프는 메모리 2GB의 가상 머신에서 VirusTotal 샘플을 실행해 만들었고, 이어서 **그 기계에서** 애플리케이션을 실행해 정상 덤프를 만들었다고 썼다. Carrier et al.의 원 논문과 함께, 정상과 악성이 같은 가상 머신에서 수집되었다는 **독립적인 근거**가 된다.

## 6. 결과

| 순위 | 모델 | 정확도 | 비고 |
|---|---|---|---|
| 1 | **로지스틱 회귀** | **99.97%** | AUC 100% |
| 2 | 그래디언트 부스팅 트리 | 99.94% | |

---

## 7. 비판적으로 읽기

### 7.1 선형 모델이 거의 완벽하다는 것의 의미
로지스틱 회귀는 클래스를 직선(평면) 하나로 가른다. 그것만으로 99.97%가 나온다면, 두 클래스가 특징 공간에서 **거의 완전히 떨어져 있다**는 뜻이다. 본 연구가 분기 하나짜리 결정트리로 99.65%를 얻은 것과 같은 방향의 관찰이다. 정확도가 높은 이유가 모델의 능력이 아니라 데이터의 성질에 있을 수 있다.

### 7.2 무작위 분할
CIC-MalMem-2022는 실행 하나에서 덤프가 10개씩 나온다. 덤프 단위로 무작위 분할하면 **같은 실행의 덤프가 학습과 시험에 함께** 들어갈 수 있다. 본 연구는 이를 막으려고 실행 단위로 묶어 교차검증했고, 무작위 분할과의 차이는 깊이 3 결정트리에서 약 0.04%p였다(본 연구 4.1 표 1 각주). 당시엔 흔한 방식이었으므로 **비판하는 형태로 쓰지 않는다**.

### 7.3 논문 안의 불일치
초록은 가장 낮은 정확도를 낸 모델을 **나이브 베이즈 98.41%**로, 본문 결과는 **MLP 97.67%**로 서로 다르게 적고 있다. 본 연구는 최고치만 인용하므로 영향은 없다.

### 7.4 ⚠️ 본 연구가 저지른 실수 — 2차 인용의 수치
- 이 논문을 처음 알게 된 것은 **다른 논문의 참고문헌 서술**을 통해서였고, 그때 "최대 99.9%"로 기록했다
- 원문을 직접 보니 **99.97%**였다. 2차 서술이 수치를 뭉뚱그린 것이다
- **교훈**: 다른 논문이 요약한 수치를 그대로 옮기지 않는다(본 연구 재발 방지 체크리스트 2번)

## 9. 스스로 점검하기

**Q1.** 로지스틱 회귀가 99.97%를 냈다는 사실에서 데이터에 대해 무엇을 추측할 수 있는가?
<details><summary>답</summary>두 클래스가 특징 공간에서 선형 경계 하나로 거의 완전히 갈린다. 복잡한 모델이 필요 없을 만큼 과제가 쉬울 수 있다는 신호다.</details>

**Q2.** 70/30 무작위 분할을 10회 반복하는 방식은 어떤 점에서 CIC-MalMem-2022에 맞지 않을 수 있는가?
<details><summary>답</summary>실행 하나에서 덤프가 10개 나오므로, 덤프 단위로 무작위 분할하면 같은 실행의 덤프가 학습과 시험에 나뉘어 들어간다. 반복 횟수를 늘려도 이 문제는 그대로 남는다.</details>

**Q3.** 이 논문이 "같은 가상 머신"이라는 사실의 독립적인 근거가 되는 이유는?
<details><summary>답</summary>원 논문(Carrier et al.)과 별개로, 이 논문도 데이터셋 설명에서 악성 덤프를 만든 뒤 "그 기계에서" 정상 덤프를 만들었다고 서술했다.</details>

**Q4.** 본 연구가 이 논문의 수치를 처음에 잘못 기록한 이유와 교훈은?
<details><summary>답</summary>원문이 아니라 다른 논문의 참고문헌 서술을 통해 알게 되어 "최대 99.9%"로 기록했다. 원문은 99.97%였다. 2차 인용의 수치는 원문에서 다시 확인해야 한다.</details>
